## Exercises & Solutions

### 1. Orders Issued by Salesman 'Paul Adam'
Find all orders issued by the salesman 'Paul Adam'. Return ord_no, purch_amt, ord_date, customer_id, salesman_id.

```sql
SELECT *
FROM orders
WHERE salesman_id =
    (SELECT salesman_id
     FROM salesman
     WHERE name='Paul Adam');
```

### 2. Orders Generated by London-Based Salespeople
Find all orders generated by London-based salespeople.

```sql
SELECT *
FROM orders
WHERE salesman_id IN
    (SELECT salesman_id
     FROM salesman
     WHERE city='London');
```

### 3. Orders from Salespeople Handling Customer ID 3007
Find all orders generated by the salesperson who works for customer 3007.

```sql
SELECT *
FROM orders
WHERE salesman_id =
    (SELECT DISTINCT salesman_id
     FROM orders
     WHERE customer_id = 3007);
```

### 4. Orders Exceeding Average Value on 10-Oct-2012
Orders whose value is greater than the average order value for 10th October 2012.

```sql
SELECT * FROM orders
WHERE purch_amt > (SELECT AVG(purch_amt) FROM orders WHERE ord_date = '10/10/2012');
```

### 5. Orders Generated in New York City
All orders generated by New York-based salespeople.

```sql
SELECT *
FROM orders
WHERE salesman_id IN
    (SELECT salesman_id
     FROM salesman
     WHERE city = 'New York');
```

### 6. Commission of Salespeople in Paris
Commissions of salespeople who service customers in Paris.

```sql
SELECT commission
FROM salesman
WHERE salesman_id IN
    (SELECT salesman_id
     FROM customer
     WHERE city = 'Paris');
```

### 7. Customers with ID Below 2001 Under Salesperson Mc Lyon
Customer whose id equals Mc Lyon's salesman_id minus 2001.

```sql
SELECT *
FROM customer
WHERE customer_id = (SELECT salesman_id - 2001
                     FROM salesman
                     WHERE name = 'Mc Lyon');
```

### 8. Count of Customers with Above-Average Grades in New York City
Count customers whose grade exceeds the average grade of New York customers, grouped by grade.

```sql
SELECT grade, COUNT(*)
FROM customer
GROUP BY grade
HAVING grade >
    (SELECT AVG(grade)
     FROM customer
     WHERE city = 'New York');
```

### 9. Orders of Salespeople with Maximum Commission
Orders placed by the salesperson(s) who earned the maximum commission.

```sql
SELECT ord_no, purch_amt, ord_date, salesman_id
FROM orders
WHERE salesman_id IN (
    SELECT salesman_id
    FROM salesman
    WHERE commission = (
        SELECT MAX(commission)
        FROM salesman
    )
);
```

### 10. Customers Who Placed Orders on 17th August 2012
Return order and customer details for orders placed on 2012-08-17.

```sql
SELECT b.*, a.cust_name
FROM orders b, customer a
WHERE a.customer_id = b.customer_id
AND b.ord_date = '2012-08-17';
```

### 11. Salespeople with More Than One Customer
Salespeople who handle more than one customer. Return salesman_id and name.

```sql
SELECT salesman_id, name
FROM salesman a
WHERE 1 <
    (SELECT COUNT(*)
     FROM customer
     WHERE salesman_id = a.salesman_id);
```

### 12. Orders with Amount Above Average Order Value
Orders where amount exceeds that customer's own average purchase amount (correlated subquery).

```sql
SELECT *
FROM orders a
WHERE purch_amt >
    (SELECT AVG(purch_amt) FROM orders b
     WHERE b.customer_id = a.customer_id);
```

### 13. Orders with Amount ≥ Average Order Value
Same as #12 but inclusive (`>=`).

```sql
SELECT *
FROM orders a
WHERE purch_amt >=
    (SELECT AVG(purch_amt) FROM orders b
     WHERE b.customer_id = a.customer_id);
```

### 14. Show Order Sums by Date Exceeding Max Order by 1000
Dates where the total order amount exceeds the max single order for that date by at least 1000.

```sql
SELECT ord_date, SUM(purch_amt)
FROM orders a
GROUP BY ord_date
HAVING SUM(purch_amt) >
    (SELECT 1000.00 + MAX(purch_amt)
     FROM orders b
     WHERE a.ord_date = b.ord_date);
```

### 15. Show All Customers If Any Are Located in London
Return all customer rows, gated on at least one customer being based in London.

```sql
SELECT customer_id, cust_name, city
FROM customer
WHERE EXISTS
   (SELECT *
    FROM customer
    WHERE city='London');
```

### 16. Find Salespeople Handling Multiple Customers
Salespeople who deal with more than one distinct customer.

```sql
SELECT *
FROM salesman
WHERE salesman_id IN (
   SELECT DISTINCT salesman_id
   FROM customer a
   WHERE EXISTS (
      SELECT *
      FROM customer b
      WHERE b.salesman_id = a.salesman_id
      AND b.cust_name <> a.cust_name
   )
);
```

### 17. Find Salespeople Handling Only One Customer
Inverse of #16 — salespeople with exactly one customer.

```sql
SELECT *
FROM salesman
WHERE salesman_id IN (
   SELECT DISTINCT salesman_id
   FROM customer a
   WHERE NOT EXISTS (
      SELECT * FROM customer b
      WHERE a.salesman_id = b.salesman_id
      AND a.cust_name <> b.cust_name
   )
);
```

### 18. Find Salespeople Handling Customers with Multiple Orders
Salespeople who have at least one customer with more than one order.

```sql
SELECT *
FROM salesman a
WHERE EXISTS
   (SELECT * FROM customer b
    WHERE a.salesman_id = b.salesman_id
    AND 1 <
        (SELECT COUNT (*)
         FROM orders
         WHERE orders.customer_id = b.customer_id)
   );
```

### 27. Calculate Total Order Amount by Salespeople in Customer Cities
Total order amount per salesperson, restricted to salespeople based in a city where a customer also lives.

```sql
SELECT salesman.name, salesman.city, subquery1.total_amt
FROM salesman,
   (SELECT salesman_id, SUM(orders.purch_amt) AS total_amt
    FROM orders
    GROUP BY salesman_id) subquery1
WHERE subquery1.salesman_id = salesman.salesman_id
AND salesman.city IN (SELECT DISTINCT city FROM customer);
```

### 28. Find Customers with Grades Different from Those in London
Customers whose grade doesn't match any London customer's grade.

```sql
SELECT *
FROM customer
WHERE grade <> ALL
   (SELECT grade FROM customer WHERE city='London' AND NOT grade IS NULL);
```

### 29. Find Customers with Grades Different from Those in Paris

### 30. Find Customers with Grades Different from Any in Dallas
Same idea using `NOT ... = ANY`.

### 31. Calculate Average Price of Products by Manufacturer
Average product price grouped by company (item_mast / company_mast).

```sql
SELECT AVG(pro_price) AS "Average Price",
       company_mast.com_name As "Company"
FROM item_mast, company_mast
WHERE item_mast.pro_com = company_mast.com_id
GROUP BY company_mast.com_name;
```

### 32. Calculate Average Price of Manufacturer's Products (≥ 350)
Same as #31, restricted to companies averaging ≥350.

```sql
SELECT AVG(pro_price) AS "Average Price",
       company_mast.com_name AS "Company"
FROM item_mast, company_mast
WHERE item_mast.pro_com = company_mast.com_id
GROUP BY company_mast.com_name
HAVING AVG(pro_price) >= 350;
```

### 33. Find Most Expensive Product of Each Company
Correlated-subquery variant of the JOINS-set "most expensive product" problem.

```sql
SELECT P.pro_name AS "Product Name",
       P.pro_price AS "Price",
       C.com_name AS "Company"
FROM item_mast P, company_mast C
WHERE P.pro_com = C.com_id
AND P.pro_price =
     (
       SELECT MAX(P.pro_price)
         FROM item_mast P
         WHERE P.pro_com = C.com_id
     );
```

### 38. Find Departments with More Than Two Employees
Subquery variant of the JOINS-set equivalent problem.

```sql
SELECT dpt_name FROM emp_department
WHERE dpt_code IN
(
  SELECT emp_dept
  FROM emp_details
  GROUP BY emp_dept
  HAVING COUNT(*) > 2
);
```

### 39. Find Employees in Departments with Second Lowest Allotment
Nested subqueries to find the second-lowest `dpt_allotment`, then the employees in that department.

```sql
SELECT emp_fname, emp_lname
FROM emp_details
WHERE emp_dept IN (
  SELECT dpt_code
  FROM emp_department
  WHERE dpt_allotment = (
    SELECT MIN(dpt_allotment)
    FROM emp_department
    WHERE dpt_allotment > (
      SELECT MIN(dpt_allotment)
      FROM emp_department
    )
  )
);
```
